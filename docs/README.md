# Документация SPI

Единственный нормативный обзор provider-neutral контракта расположен в
[корневой документации](../../docs/provider-spi.md). Он описывает capability,
модели, потребителей и текущие реализации. JavaDoc рядом с интерфейсами
дополняет этот обзор точной семантикой методов.

Изменяя SPI, обновляйте оба уровня документации и добавляйте проверки в
`corelia-provider-tck`; изменение интерфейса является межмодульным контрактом.
